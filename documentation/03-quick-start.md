# Quick Start

[Prev: Installation](./02-installation.md) | [Index](./index.md) | [Next: Configuration Options](./04-configuration-options.md)

Add the Bugscribe button to your page:

```js
const bugscribe = new window.Bugscribe({
  button: {
    position: { vertical: "bottom", horizontal: "right" },
    bgColor: "#ff5733",
  },
});
```
