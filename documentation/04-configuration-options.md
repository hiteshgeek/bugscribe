# Configuration Options

[Prev: Quick Start](./03-quick-start.md) | [Index](./index.md) | [Next: UI Components](./05-ui-components.md)

- `button`: Customize color, position, icon
- `screenshot`: Default shape, dimensions position
- `maxRecordingSeconds`: Limit video recording duration
- `captureMicrophone`: Enable/disable mic capture
