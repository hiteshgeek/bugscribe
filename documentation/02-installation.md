# Installation

[Prev: Introduction](./01-introduction.md) | [Index](./index.md) | [Next: Quick Start](./03-quick-start.md)

Install via npm, yarn, or include the compiled assets in your HTML:

```bash
npm install bugscribe
# or
yarn add bugscribe
```

Or include via CDN:

```html
<link rel="stylesheet" href="https://cdn.bugscribe.com/v1/bugscribe.min.css" />
<script src="https://cdn.bugscribe.com/v1/bugscribe.min.js"></script>
```
