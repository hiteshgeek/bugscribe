# MediaCapture

Handles screenshot and video recording logic.

## Features & Options

- Capture full page, visible area, custom region
- Video recording with microphone support
- Returns blob URLs for preview

## Variations

- Can be extended for new capture modes
- Configurable recording duration and quality
