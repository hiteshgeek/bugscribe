# CustomVideoPlayer

Custom video player for previewing recorded videos.

## Features & Options

- Timer and seeker bar
- Play/pause, download, close controls
- Handles blob URLs and video metadata

## Variations

- Can be styled via SCSS
- Supports autoplay and manual playback
