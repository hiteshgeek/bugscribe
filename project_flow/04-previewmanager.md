# PreviewManager

Handles display of image and video previews, modal viewers, and download/delete actions.

## Features & Options

- Redraws previews from Bugscribe's \_screenshotPreviews
- Modal viewer with zoom, pan, and download
- Custom video player integration
- Event hooks for preview click and delete

## Variations

- Can be extended for custom preview layouts
- Supports both image and video types
