# BugButtonWrapper

Manages the floating action button and its child actions (screenshot, record, settings).

## Features & Options

- Vertical icon stack for screenshot options
- Customizable button color and position
- Handles open/close animation
- Event listeners for all actions

## Variations

- Can show/hide individual buttons
- Supports custom icons via config
