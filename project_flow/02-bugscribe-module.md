# Bugscribe Module

The main entry point. Handles configuration, event binding, and orchestrates all other modules.

## Features & Options

- `button`: position, color, icon
- `screenshot`: shape, dimensionsPosition
- `maxRecordingSeconds`: number (default: 120)
- `captureMicrophone`: boolean
- Event hooks: onScreenshot, onRecord, onPreview, onDelete

## Variations

- Can be initialized with minimal config for default behavior.
- Supports advanced config for custom UI and capture modes.
